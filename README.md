A simple and efficient Student Management System built using SQL for database management. This project is designed to handle student records such as registration, updating details, deleting records, and retrieving student information efficiently. It demonstrates strong fundamentals of database design, query optimization, and data manipulation using SQL.

Features:

1.Add New Student — Insert new student details into the database.
2.View All Students — Retrieve and display the list of all students.
3.Search Student — Find student details by ID or name.
4.Update Details — Modify student information (like marks, contact, or course).
5.Delete Student Record — Remove a student entry from the database.
6.Organized Structure — Proper use of primary keys, foreign keys, and normalization principles.
